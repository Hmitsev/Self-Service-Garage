# Сервиз за самообслужване - стартова версия

## Стартиране локално
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Първи вход
- Клиент: създай първия профил от началния екран.
- Администратор: началният PIN е `2468`.
- Веднага след първия вход смени PIN от **Админ > Настройки**.
- За Render може да зададеш environment variable `ADMIN_PIN` преди първото стартиране на празна база.

## Render
- Build command: `pip install -r requirements.txt`
- Start command: `streamlit run app.py --server.address 0.0.0.0 --server.port $PORT`

## QR код
След deploy QR кодът трябва да сочи към публичния URL на приложението. Началният таб е регистрацията, затова нов клиент влиза директно в бързия поток.

## Какво работи
- клиентска регистрация с камера/качване на профилна снимка;
- вход на клиент и администратор;
- часови слотове и защита от двойна резервация;
- заявка за части, VIN и снимане/качване на талон;
- правило за минимум 1 ден предварително при части;
- история и отговори от администратора;
- PIN поле за smart lock;
- технически сигнали със снимка;
- 3 YouTube видеа, управлявани от админ панела;
- SQLite база за стартова/тестова версия.

## Важно преди реален клиент
За production замени локалната SQLite база и локалните uploads с PostgreSQL/Neon и object storage. При Render локалната файлова система може да не е подходяща за трайно съхранение. Smart-lock интеграцията засега е подготвена като поле и процес, но конкретното API зависи от модела брава.
